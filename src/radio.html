How the deck works in this demo We hold no licensed masters, so the docked deck runs a real transport against each track’s true running time and hands off to the rights holder’s own Spotify or YouTube player for actual audio. Drop an MP3 URL into the audio field in data/catalog.js and the same deck streams it instead — nothing else changes. Continuous audio across a page load needs a single-page shell; that trade-off is written up in the README.
